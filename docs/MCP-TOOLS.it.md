# Strumenti MCP di OpenBand

🇬🇧 [English](MCP-TOOLS.md) · 🇮🇹 Italiano · [← README](../README.it.md)

Gli stessi strumenti servono ai client MCP e alla chat dentro la pagina (sono definiti una volta sola, in `server/tools.mjs`).

**Livelli**: 24 strumenti core (22 nella pagina, che gestisce da sé il passo di annullamento) e 7 capability sono sempre caricati; gli altri arrivano a gruppi (editing, structure, mix, analysis, recording, versions, lyrics, plugins, sounds, files, collab, jam, engines) con `load_toolset({name})`. La chat nella pagina usa i livelli (e precarica i gruppi che una richiesta chiede in modo evidente); i client MCP ricevono tutti gli strumenti, a meno che il server non parta con `--toolsets=core`: allora `load_toolset` li aggiunge con una notifica `tools/list_changed`. Vedi [AI-MODELS.it.md](AI-MODELS.it.md).

| Area | Strumenti |
|---|---|
| Progetto | `pair_studio` (solo MCP remoto), `open_studio` (solo locale), `get_project`, `get_status`, `list_instruments`, `new_project`, `rename_project`, `set_tempo`, `set_key`, `set_master_volume`, `export_project_json`, `import_project_json` |
| Eventi dello studio | `get_events`, `wait_for_event` (frasi che suoni, selezione, trasporto, modifiche, domande da *Chiedi all'AI*); risorsa `openband://project` con notifiche delle modifiche |
| Annulla | `begin_change` / `end_change` (un passo di annullamento per richiesta, con etichetta), `get_history` (con `plugins_changed` per passo), `undo` / `redo` (con `steps`; stato dei plugin compreso) |
| Tracce | `add_track` (strumento, batteria o audio), `update_track` (strumento, volume, pan, mute, solo, riverbero, eco, tono), `delete_track` |
| Suoni | `import_sample`, `list_samples`, `create_sampler_instrument`, `import_soundfont`, `add_audio_region`, `detect_tempo` (il BPM di un loop dal nome o dagli attacchi), `set_synth_params` (i parametri di un synth: inviluppi, filtro, FM, onda, unisono; senza valori, l'elenco con i range), `sound_from_words` (una descrizione → una patch), `match_sound` (una nota → le 3 patch più vicine, con la somiglianza), `tone_match` (EQ e drive di una traccia audio verso un riferimento), `apply_patch` — i file si leggono da un percorso locale o da un URL http(s) |
| Struttura | `get_structure` (sezioni con profilo di energia), `add_section`, `update_section`, `delete_section`, `move_section`, `duplicate_section` (con ripple), `split_region`, `auto_sections`; disegna la canzone: `set_energy_curve` (punti o una forma: pop, slow_build, edm_drop, ballad), `get_energy` (disegnata e misurata, per battuta), `arrange_from_energy` (un arrangiamento completo su un branch), `add_transition` (riser, downlifter, piatto al contrario, fill, stop, impact) |
| Testi | `set_lyrics`, `get_lyrics`, `align_lyrics`, `check_prosody`, `suggest_melody_rhythm`, `export_chord_sheet` (ChordPro o testo, `save_to` opzionale) |
| Linter | `lint_project` (regole simboliche, opzionalmente audio), `apply_fix`, `ignore_issue`; `update_notes` modifica le note sul posto |
| Ascolto | `analyze_mix` (battute o sezione, per traccia, summary/full), `render_spectrogram` (restituisce un'immagine), `detect_key` (MIDI, audio o entrambi), `analyze_harmony` (accordi, numeri romani, funzioni, cadenze) |
| Multiplayer | `create_room` (LAN o peer to peer, password facoltativa), `join_room`, `leave_room`, `get_peers` |
| Jam | `set_jam_mode` (traccia di risposta, finestra), `play_phrase` (note effimere a `next_bar`, `next_loop` o a una battuta; `commit` opzionale; restituisce un `phrase_id`), `keep_answer`, `keep_phrase({phrase_id})` (una qualunque delle ultime 20 risposte); le frasi dell'utente arrivano come eventi `phrase`. Jam dal vivo con un motore in tempo reale (`stream.jam`): `start_live_jam` (motore, traccia, stile, intensità, accordi, registrazione), `steer_live_jam` (stile, intensità, accordi; restituisce latenza, buchi, frame in ritardo), `stop_live_jam({keep})` (una regione, o una take della jam a quella battuta) |
| Versioni | `save_version`, `list_versions`, `create_branch`, `checkout` (branch o versione, annullabile, salva il WIP), `diff_versions` (riepilogo leggibile + modifiche strutturate), `merge` (a tre vie; `strategy` e `pick` per entità); `export_project_json` con `canonical` |
| Ensemble e contesto | `create` (una parte a parole, dai motori di OpenBand o dai motori OMEP installati; varianti come take), `transform` (continua, armonizza, ridipingi, cambia stile a una parte che c'è), `separate` (una regione audio in batteria, basso, altro e voce, nel browser), `sing` (una voce canta la melodia sul testo, con i suoi fonemi), `get_context` e le risorse `openband://context/song`, `/section/<id>`, `/bars/<a>-<b>` (il Song Context Package), `cover_song` (l'audio di un brano in un altro stile, come take accanto all'originale), `list_engines`, `get_ledger`, `set_engine_policy`, `load_toolset`; prompt `loop_to_song`, `prepare_release`, `vocal_session`; `create`, `transform`, `separate`, `sing` e `arrange_from_energy` possono girare come task MCP |
| Spiegami | `annotate` (progetto, traccia, regione, note, sezione o intervallo di battute; markdown fino a 500 caratteri), `list_annotations`, `resolve_annotation`, `delete_annotation`; `get_status` riporta `teach_mode` |
| Take | `add_take`, `list_takes`, `set_active_take`, `delete_take`, `comp_takes` (segmenti, note tagliate ai confini), `start_ab_test` (test alla cieca; la classifica arriva come evento `ab_result`) |
| Altre DAW | `import_dawproject` (percorso o URL del file; sostituisce la canzone, oppure `replace: false` ne aggiunge le tracce; restituisce cosa non si è potuto convertire), `export_dawproject` (`save_to` o download) |
| Macchina del tempo | `get_timeline` (ogni passo nel journal), `preview_at({time})` (la canzone in un momento — ISO, ms o `"-20m"` — senza cambiare nulla), `restore_at({time, as_branch?})` |
| Monitoring | `get_meters` (LUFS e true peak live del master e di ogni traccia, stato rispetto all'obiettivo), `set_monitoring` (mono, dim, obiettivo, azzeramento — solo ascolto), `level_match` (quanto una catena di effetti o un plugin cambia il volume; `apply` compensa), `update_track({polarity})` |
| Errori | `add_flub` (playhead o battuta/beat; tipi flub / good / note), `list_flubs`, `resolve_flub`, `delete_flub`, `replace_with_best_take`; eventi `flub` mentre l'utente segna |
| Reference | `import_reference` (percorso o URL, estratto opzionale), `compare_to_reference` (differenze a loudness pareggiata e suggerimenti), `clear_reference` |
| Pubblicazione | `get_release` (metadati, licenza, cosa contiene il brano, piattaforme), `set_release` (titolo, artista, tag…, `license` o `choose` da tre risposte, `sample_licenses`), `check_release` (per piattaforma: conflitti di licenza, rifiuti, tag, copertina), `generate_cover` (stile, palette, seme; restituisce un'anteprima), `export_release_kit` (zip: FLAC a 24 bit con tag e copertina, cover.png, LICENSE.txt, CREDITS.txt, testo e LRC), `render_video` (16:9 tutto il brano, o uno Short 9:16 dal ritornello o da `section_id`; MP4 H.264 + AAC con copertina, spettro e testo), `list_publish_targets` (piattaforme, account, cosa blocca ciascuna), `publish` (`platforms`: archive, wikimedia, soundcloud, youtube, mixcloud, funkwhale; `privacy`; **aspetta sempre il clic dell'utente nello studio**), `get_publications` |
| Tutela | `timestamp_work` (il manifest del brano, come impronta di 32 byte, marcato in Bitcoin con OpenTimestamps; `include` master, progetto, testo, accordi), `get_protections` (in attesa o confermate; le completa), `verify_timestamp` (una prova di questo brano, o un file qualsiasi con il suo .ots), `export_proof_package` (manifest, .ots, file, README, certificate.pdf) |
| Registrazione | `record_audio` (microfono o interfaccia, conteggio, modo `audio` o `hum`; tracce armate insieme, punch con pre-roll, giri del ciclo come take; l'utente conferma), `arm_track` (canale d'ingresso per traccia), `set_track_midi_input` / `map_midi_channels` (MIDI dal vivo per canale: un dispositivo o un orchestratore MIDI pilota tante tracce), `set_punch` (battute di in/out, pre-roll), `audio_to_midi` (audio monofonico → note, aggancio alla tonalità, quantizzazione con intensità), `start_session` / `stop_session` / `get_session` (modalità Sessione: una sezione in loop, N passaggi come take valutate battuta per battuta, le battute migliori unite; eventi `session_take`, `session_done`), `set_voice_control` (comandi vocali premendo per parlare, Vosk offline o Web Speech; eventi `voice_command`, le altre frasi come eventi `ask`) |
| Mix Pilot | `mix_pilot` (mix e master per un genere, dosati, ogni modifica spiegata), `set_pilot_amount`, `fix_pilot`, `set_track_role`, `export_for_platforms` (master per piattaforma, stem, strumentale, report) |
| Mix | `set_track_effects` (passa-alto, amp, EQ, compressore con sidechain), `set_master_chain` (EQ master, glue, ampiezza, limiter true-peak, loudness per piattaforma), `set_automation` (parametro di mix, effetto o plugin), `clear_automation`, `list_automatable` |
| Plugin | `add_plugin` (da una descrizione a parole; nell'app desktop prima i plugin installati), `search_plugins`, `list_plugins`, `list_native_plugins` e `rescan_plugins` (app desktop: i plugin VST3 / CLAP / AU del computer), `add_plugin_instrument`, `add_plugin_effect`, `remove_plugin_effect`, `set_plugin_bypass`, `get_plugin_params`, `set_plugin_params`, `show_plugin` |
| File | `export_wav` (`sample_rate` 44,1–96 kHz, `bit_depth` 16 / 24 / 32 bit float, `dither`), `export_midi` (con `save_to` per salvarli in un percorso), `import_midi` |
| Regioni | `add_region`, `update_region` (per le clip audio anche `stretch_mode` follow_tempo / fixed con `ratio`, e `pitch` in semitoni), `delete_region`, `duplicate_region`, `open_editor` |
| Note | `get_region_notes`, `add_notes`, `remove_notes`, `transpose_region`, `quantize_region` e `quantize_track` (griglia con terzine, forza, swing, fine delle note; tutta la traccia o alcune battute), `suggest_continuation` (note fantasma: suggerimenti locali per continuare, linea di basso, armonizzare, contromelodia, variazione, fill di batteria) |
| Composizione | `add_drum_pattern` (stringhe di step tipo `"x...x...x...x..."`), `add_chord_progression` (`["Am7","Fmaj7","C","G"]`, stile block, arpeggio o stabs), `add_drummer` (stile, complessità, intensità, swing, fill, seed; segue le sezioni), `regenerate_drummer` (nuovo seed, anche come take) |
| Loop | `search_loops` (parole, tempo, tonalità), `add_loop` (segue tempo e tonalità della canzone; `repeat`) — una libreria CC0 fatta con OpenBand |
| Trasporto | `transport` (play, stop, toggle, rewind), `set_loop`, `set_metronome`, `open_studio` |

Convenzioni: tempo in 4/4; le battute partono da 1; dentro una regione posizioni e durate sono in movimenti (0,25 = sedicesimo); le altezze si danno come numero MIDI, come nome (`"C4"`, `"F#3"`) o, sulla batteria, come nome del pezzo (`"kick"`, `"snare"`, `"hihat"`…).
